## Entry Points for Contributors

**Start anywhere. Fork freely. No permission needed.**

### Story Entry Points

- Write a scene where a character hears the true name of a place for the first time, not from a person, but from the land itself.
- Create a monologue from the perspective of a colonial structure (a bridge, a fence, a pipeline) as it begins to hear the stories of the land it occupies.
- Draft a 'stream-of-consciousness' letter from Kǝ́ to the lead surveyor, one week after their encounter, where her thoughts blend with the river's flow.
- Imagine a council meeting where the elders do not speak with words, but with shared memories projected through touch and silence.

### Technical Entry Points

- Build an interactive web experience that layers bureaucratic documents (PDFs of surveys, permits) over an audio stream of natural sounds, allowing the user to 'scratch away' the text to reveal the underlying audio landscape.
- Create a text generator that takes colonial/technical language as input and 'translates' it into a stream-of-consciousness narrative rooted in sensory, non-human perspectives.
